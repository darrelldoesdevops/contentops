Add three new variants to the `AppError` enum in `src/error.rs`:

```rust
#[error("no speech detected in {0}: entire video is silence")]
NoSpeechDetected(PathBuf),

#[error("error in stage '{stage}': claude CLI exited with code {code}\n{stderr}")]
ClaudeFailed {
    stage: String,
    code: i32,
    stderr: String,
},

#[error("error in stage '{stage}': failed to parse output\n{message}")]
ParseFailed {
    stage: String,
    message: String,
},
```

- `ParseFailed { stage, message }` -- format as `"error: in stage '{stage}': failed to parse output\n  {message}"`
