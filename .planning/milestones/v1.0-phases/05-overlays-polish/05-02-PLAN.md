
Add to `src/ffmpeg.rs`:

**Duration probing:**
```rust
pub fn probe_duration(input: &str) -> Option<f64>
```
Runs `ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 <input>`.
Parses stdout as f64. Returns None if ffprobe fails or output isn't parseable.

**Progress-tracked FFmpeg runner:**
```rust
pub fn run_ffmpeg_with_progress(
    args: &[&str],
    total_duration_secs: Option<f64>,
    message: &str,
) -> Result<FfmpegOutput, std::io::Error>
```

Implementation:
1. If `total_duration_secs` is None, fall back to `run_ffmpeg(args)` (spinner handled by caller)
2. Spawn FFmpeg with `-progress pipe:2` appended to args (progress info goes to stderr)
3. Use `Stdio::piped()` for stderr, read line by line with `BufReader`
4. Create an indicatif `ProgressBar::new(100)` with a template showing: `{spinner:.cyan} {msg} [{bar:30.cyan/dim}] {pos}% ({elapsed})`
5. Parse lines for `out_time_ms=<microseconds>` — convert to seconds, compute percentage against total_duration
6. Update progress bar position with percentage (0-100)
7. Collect all stderr lines into a Vec for error reporting
8. On completion: finish progress bar, return FfmpegOutput with collected stderr

Keep existing `run_ffmpeg()` and `run_ffmpeg_verbose()` unchanged.

Run `cargo build`.

  </verify>
  <done>
FFmpeg wrapper has progress-tracked runner that parses `out_time_ms` from FFmpeg progress output and updates an indicatif progress bar. Ffprobe duration detection is available.
  </done>
