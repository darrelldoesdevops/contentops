<task type="auto">
  <name>Task 1: Create FFmpeg subprocess wrapper and temp file registry</name>
  <files>src/ffmpeg.rs, src/temp.rs</files>
  <action>
Create `src/ffmpeg.rs` — the FFmpeg subprocess wrapper (PIPE-02):

Define `FfmpegOutput` struct with `success: bool`, `exit_code: Option<i32>`, `stderr: Vec<u8>`.

Implement `run_ffmpeg(args: &[&str]) -> Result<FfmpegOutput, std::io::Error>`:
- Uses `std::process::Command::new("ffmpeg")`
- Appends `-y` and `-nostdin` to args programmatically (never rely on caller)
- Sets `.stdin(Stdio::null())`, `.stdout(Stdio::null())`, `.stderr(Stdio::piped())`
- Calls `.output()` (not `.spawn()` — avoids deadlock, captures stderr after completion)
- Returns `FfmpegOutput`

Implement `run_ffmpeg_verbose(args: &[&str]) -> Result<FfmpegOutput, std::io::Error>`:
- Same as above but uses `.stderr(Stdio::inherit())` instead of piped
- Returns FfmpegOutput with empty stderr vec (since it was inherited to terminal)

Create `src/temp.rs` — temp file lifecycle management (PIPE-03):

Define `TempFileRegistry` wrapping `Arc<Mutex<Vec<PathBuf>>>`:
- `new() -> Self` — creates empty registry
- `register(&self, path: PathBuf)` — adds path to the tracked list
- `remove(&self, path: &Path)` — removes path from tracked list (on successful cleanup)
- `cleanup_all(&self)` — removes all registered temp files from disk (best-effort, ignores errors)
- `clone_inner(&self) -> Arc<Mutex<Vec<PathBuf>>>` — for sharing with ctrlc handler

Implement `register_cleanup(registry: Arc<Mutex<Vec<PathBuf>>>)`:
- Calls `ctrlc::set_handler` with a closure that:
  1. Locks the mutex
  2. Iterates paths and calls `std::fs::remove_file` (ignoring errors)
  3. Calls `std::process::exit(1)`
- Use `ctrlc` with "termination" feature for SIGTERM/SIGHUP support

Implement `make_temp_file(dir: &Path, ext: &str) -> anyhow::Result<tempfile::NamedTempFile>`:
- Uses `tempfile::Builder::new().prefix(".contentops_tmp_").suffix(ext).tempfile_in(dir)`
- Wraps error with `anyhow::Context`

Run `cargo build` to verify.

  </verify>
  <done>
FFmpeg wrapper always injects -y and -nostdin, captures stderr, and reports exit codes. Temp file registry tracks paths and the ctrlc handler cleans them up on SIGINT.

<task type="auto">
  <name>Task 2: Wire cut command with spinner, FFmpeg execution, and error reporting</name>
  <files>src/commands/cut.rs, src/main.rs</files>
  <action>
Update `src/main.rs`:
- Create `TempFileRegistry` before command dispatch
- Call `register_cleanup(registry.clone_inner())` to set up the ctrlc handler
- Pass `registry` to `commands::cut::run()`
- Add `mod ffmpeg;` and `mod temp;` declarations

Update `src/commands/cut.rs` to implement a full passthrough pipeline:

The `run` function signature: `pub fn run(args: CutArgs, verbose: bool, registry: &TempFileRegistry) -> anyhow::Result<()>`

Implementation flow:
1. Call `require_ffmpeg()?` — detect FFmpeg
2. Validate input file exists, return `AppError::InputNotFound` if not
3. Derive output path: if `-o` provided use that, else use `derive_output_path(&args.input, "cut")` (stem + `_cut.mp4` in same directory)
4. Create a temp file using `make_temp_file(parent_dir, ".mp4")` for the FFmpeg output
5. Register the temp file path with `registry.register(temp_path.clone())`
6. If NOT verbose: start an indicatif spinner with message `"Processing {filename}..."` using `ProgressBar::new_spinner()` with a cyan spinner style and 80ms tick rate
7. If verbose: print `"Running: ffmpeg {args}"` (show the full FFmpeg command for debugging)
8. Build FFmpeg args for a simple re-encode: `["-i", input_path, "-c:v", "libx264", "-c:a", "aac", temp_output_path]` — this is a stub that Phase 2 replaces with silence removal filters
9. Call `run_ffmpeg(&ffmpeg_args)` (or `run_ffmpeg_verbose` if `--verbose`)
10. On success:
    - Persist the temp file to the final output path (rename/copy)
    - Remove temp file from registry
    - Get file size using `std::fs::metadata`, format with `humansize` using DECIMAL (SI) convention
    - Finish spinner with green "Created {output_path} ({size})" message
11. On FFmpeg failure:
    - Clear spinner with `finish_and_clear()`
    - Extract last 20 lines of stderr using `last_n_lines`
    - Save full stderr to a log file at `{input_dir}/.contentops_error.log`
    - Return `AppError::FfmpegFailed` with stage "re-encode", exit code, and truncated stderr
12. Temp file cleanup happens automatically: NamedTempFile drops on scope exit, and ctrlc handler covers SIGINT

In verbose mode, skip the spinner entirely — just let FFmpeg stderr stream to the terminal naturally. Print the success/error message directly to stderr after FFmpeg completes.

Run `cargo build` and `cargo clippy`.
