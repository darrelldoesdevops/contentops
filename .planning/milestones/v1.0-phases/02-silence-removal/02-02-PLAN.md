  <action>
    **In src/ffmpeg.rs**, add two new functions:

    1. `run_silencedetect(input: &str, threshold_db: f64, min_duration: f64) -> Result&lt;String, std::io::Error&gt;`
       - Runs: `ffmpeg -i {input} -af silencedetect=noise={threshold_db}dB:d={min_duration} -f null -`
       - Captures stderr (this is where silencedetect output goes)
       - Returns stderr as String for parsing
       - Uses `-nostdin` flag like existing wrappers

    2. `probe_duration(input: &str) -> Result&lt;f64, std::io::Error&gt;`
       - Runs: `ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 {input}`
       - Captures stdout, parses as f64
       - Returns video duration in seconds

  <action>
    **In src/main.rs**, ensure `mod silence;` is declared (if not already added by Plan 01).

    **In src/commands/cut.rs**, replace the existing `run()` function body with the full silence removal pipeline:

    1. **Detect phase** — update spinner to "Detecting silence in {filename}..."
       - Call `ffmpeg::probe_duration()` to get video duration
       - Call `ffmpeg::run_silencedetect()` with hardcoded defaults: threshold -30dB, min duration 0.5s
       - Parse stderr with `silence::parse_silencedetect()`
       - If no silence detected, print message "No silence detected in {filename}" and exit successfully (no output file)

    2. **Dry-run branch** — if `args.dry_run`:
       - Print header: "Silence detected in {filename}:"
       - For each SilenceInterval: print "  {start:.1}s - {end:.1}s ({duration:.1}s)"
       - Print blank line
       - Print "Total silence: {total:.1}s"
       - Print "Would remove {total:.1}s from {duration:.1}s video"
       - Return Ok(()) without producing output file

    3. **Removal phase** — update spinner to "Removing silence..."
       - Call `silence::silence_to_speech()` with 0.2s padding
       - If no speech segments remain, return error "No speech detected"
       - Build select filter via `silence::build_select_filter()` — use 30.0 fps as default frame rate (or probe it; implementer's discretion)
       - Build aselect filter via `silence::build_aselect_filter()`
       - Construct FFmpeg args:
         ```
         -i {input}
         -vf {select_filter}
         -af {aselect_filter}
         -c:v libx264 -crf 23 -pix_fmt yuv420p
         -c:a aac -b:a 192k
         {temp_output}
         ```
       - Run FFmpeg (reuse existing run_ffmpeg/run_ffmpeg_verbose based on verbose flag)

    4. **Finish** — copy temp to output, cleanup temp, show success message:
       - "Created {output} ({size})"
       - "Removed {silence_total:.1}s of silence"

    The existing error handling pattern (FfmpegFailed, StageIo, error log writing) should be preserved. Update the stage name from "re-encode" to "silence-detect" or "silence-remove" as appropriate for each FFmpeg call.

    Add `AppError::NoSilenceDetected` or use a simple info message (implementer's discretion) for the no-silence case.
