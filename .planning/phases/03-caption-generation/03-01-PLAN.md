<task type="auto">
  <name>Task 2: Full caption pipeline — audio extraction, whisper-cpp invocation, SRT + JSON output</name>
  <files>src/commands/caption.rs</files>
  <action>
Implement the full caption pipeline in `src/commands/caption.rs`. Follow the same patterns as `cut.rs` (spinner, error handling, temp file cleanup, derive_output_path).

**Structs** (at top of file):
- `Word { text: String, start: f64, end: f64 }` — internal representation of a timestamped word
- `SrtEntry { index: usize, start: f64, end: f64, text: String }` — a single SRT subtitle entry

**The `run` function pipeline:**

1. **Validation**: Call `require_ffmpeg()` and `require_whisper()`. Check `args.input.exists()`. Check `args.model.exists()` — if not, return `AppError::ModelNotFound(args.model)`.

2. **Derive output paths**: Reuse the `derive_output_path` pattern from `cut.rs` but produce `.srt` extension. Create a helper `derive_caption_output(input, suffix, ext)` that works like `derive_output_path` but takes an extension parameter. SRT goes to `input_captioned.srt`, JSON sidecar goes to `input_captioned.json`. If `-o` flag is set, use it for SRT and derive JSON by changing its extension.

3. **Audio extraction stage**: Create spinner with message "Extracting audio...". Create temp WAV file via `make_temp_file(parent_dir, ".wav")`, register with registry. Run FFmpeg: `ffmpeg -i input.mp4 -ar 16000 -ac 1 -f wav temp.wav`. Check success, handle errors with stage name "audio-extraction". Finish spinner on success.

4. **Transcription stage**: Create spinner with message "Transcribing with Whisper...". Shell out to whisper-cpp:
   ```
   whisper-cpp -m model.bin -f temp.wav --output-json --max-len 1 -l en
   ```
   Use `std::process::Command::new("whisper-cpp")` with `.arg()` calls (NOT the ffmpeg wrapper — whisper-cpp is a separate binary). Capture stdout AND stderr. Check exit code — if non-zero, return `AppError::WhisperFailed { stage: "transcription", code, stderr }`.

5. **Parse JSON output**: whisper-cpp `--output-json` writes a `.wav.json` file next to the input WAV (not to stdout). Read the JSON file at `{temp_wav_path}.json`. Parse with serde_json. The whisper-cpp JSON structure has a `transcription` array where each element has `timestamps: { from, to }` and `text` fields. When using `--max-len 1`, each segment is approximately one word. Extract into `Vec<Word>` — trim whitespace from text, convert `from`/`to` timestamp strings (format "HH:MM:SS.mmm") to f64 seconds. If transcription array is empty, print a warning "No speech detected in video" and write empty SRT + JSON files.

6. **Generate SRT output**: Group words into subtitle entries of 3-5 words each. Break on punctuation (`.`, `!`, `?`, `,`) or at 5 words max. Each `SrtEntry` has: start time = first word's start, end time = last word's end, text = words joined with spaces. Format as standard SRT:
   ```
   1
   00:00:01,200 --> 00:00:03,400
   Hello world this is

   2
   00:00:03,400 --> 00:00:05,800
   a test video
   ```
   Write to SRT output path. Helper function `format_srt_time(seconds: f64) -> String` converts f64 to `HH:MM:SS,mmm` format.

7. **Generate JSON sidecar**: Serialize `Vec<Word>` as `[{"word": "Hello", "start": 1.2, "end": 1.5}, ...]` using serde_json::to_string_pretty. Write to JSON output path.

8. **Cleanup**: Remove temp WAV file and temp JSON file from registry. Print success message with output paths and file sizes (same style as cut.rs).

**Verbose mode**: When verbose, skip spinners and print command being run (same pattern as cut.rs).

**Error handling**: Follow existing patterns — capture stderr, truncate with `last_n_lines`, return typed errors. Clean up temp files on all paths.
