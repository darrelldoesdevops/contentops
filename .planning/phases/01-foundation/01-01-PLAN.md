<task type="auto">
  <name>Task 2: Implement error types with stage context and FFmpeg PATH detection</name>
  <files>src/error.rs, src/main.rs</files>
  <action>
Create `src/error.rs` with a typed `AppError` enum using `thiserror`:

```rust
#[derive(Error, Debug)]
pub enum AppError {
    #[error("ffmpeg not found on PATH\n  hint: brew install ffmpeg")]
    FfmpegNotFound,

    #[error("error in stage '{stage}': ffmpeg exited with code {code}\n{stderr}")]
    FfmpegFailed {
        stage: String,
        code: i32,
        stderr: String,
    },

    #[error("error in stage '{stage}': {source}")]
    StageIo {
        stage: String,
        #[source]
        source: std::io::Error,
    },

    #[error("input file not found: {0}")]
    InputNotFound(PathBuf),
}
```

Add a public function `require_ffmpeg() -> Result<PathBuf, AppError>` that uses `which::which("ffmpeg")` and maps the error to `AppError::FfmpegNotFound`.

Add a helper function `last_n_lines(stderr: &[u8], n: usize) -> String` that extracts the last N lines from FFmpeg stderr output (for truncated display).

Add a helper function `format_error(err: &AppError) -> String` that uses `owo_colors` to produce rustc-style output:
- Red bold "error:" prefix
- Bold stage name where applicable
- Indented stderr lines (2-space indent)

Update `src/main.rs` to handle errors from command dispatch: catch `anyhow::Error`, downcast to `AppError` if possible, print using `format_error`, and exit with code 1. For non-AppError anyhow errors, print with red "error:" prefix.

Update `src/commands/cut.rs` to use `require_ffmpeg()?` at the start, and return `AppError::InputNotFound` if the input file doesn't exist.

Run `cargo build` and `cargo clippy`.
  </action>

`cargo build` succeeds. `cargo clippy` has no warnings. With FFmpeg uninstalled (or PATH modified), `contentops cut test.mp4` prints the red "ffmpeg not found" error with the brew install hint. With FFmpeg installed, `contentops cut nonexistent.mp4` prints "input file not found" error.
  </verify>
  <done>
Error types are defined with stage context fields. FFmpeg detection works and produces an actionable error with install hint. Input validation produces a clear file-not-found error. All errors use colored, structured formatting.
  </done>
