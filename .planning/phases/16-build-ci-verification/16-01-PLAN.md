  <files>.github/workflows/ci.yml, .github/workflows/release.yml</files>
  <action>
**ci.yml changes:**

1. Add `ORT_CACHE_DIR` to the top-level env section:
```yaml
env:
  CARGO_TERM_COLOR: always
  ORT_CACHE_DIR: ~/.ort-cache
```

2. Replace the simple `os` matrix with an explicit include matrix supporting 4 targets:
```yaml
strategy:
  matrix:
    include:
      - os: macos-latest
        target: aarch64-apple-darwin
      - os: macos-latest
        target: x86_64-apple-darwin
      - os: ubuntu-latest
        target: x86_64-unknown-linux-gnu
      - os: windows-latest
        target: x86_64-pc-windows-msvc
```

3. Update the job name to show target: `name: Check (${{ matrix.target }})`

4. After the `dtolnay/rust-toolchain@stable` step, add a step to install the target if cross-compiling:
```yaml
- name: Add target
  run: rustup target add ${{ matrix.target }}
```

5. Update `Swatinem/rust-cache@v2` to include ORT cache:
```yaml
- uses: Swatinem/rust-cache@v2
  with:
    cache-directories: ~/.ort-cache
```

6. Update Clippy to use the target:
```yaml
- name: Clippy
  run: cargo clippy --target ${{ matrix.target }} -- -D warnings
```

7. Run tests only on native targets (skip x86_64-apple-darwin on ARM runner -- exec format error):
```yaml
- name: Tests
  if: matrix.target != 'x86_64-apple-darwin'
  run: cargo test --target ${{ matrix.target }}
```

8. Keep Format check as-is (host-only, no target needed).

9. Run security audit only once (not per-platform) by adding a condition:
```yaml
- name: Security audit
  if: matrix.target == 'aarch64-apple-darwin'
  run: |
    cargo install cargo-audit --locked
    cargo audit
```
