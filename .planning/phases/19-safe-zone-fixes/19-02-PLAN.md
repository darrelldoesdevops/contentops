**1. Add `scale_to_tiktok()` to `src/ffmpeg.rs`:**

Add this function after `extract_16k_wav()`:

```rust
pub fn scale_to_tiktok(input: &str, output: &str, verbose: bool) -> Result<FfmpegOutput, std::io::Error> {
    let vf = format!(
        "scale={}:{}:force_original_aspect_ratio=increase,crop={}:{}",
        crate::tiktok::OUTPUT_WIDTH,
        crate::tiktok::OUTPUT_HEIGHT,
        crate::tiktok::OUTPUT_WIDTH,
        crate::tiktok::OUTPUT_HEIGHT,
    );
    let args = [
        "-i", input,
        "-vf", &vf,
        "-c:v", "libx264",
        "-crf", "14",
        "-preset", "slow",
        "-pix_fmt", "yuv420p",
        "-c:a", "copy",
        output,
    ];
    if verbose {
        eprintln!("Running: ffmpeg {}", args.join(" "));
        run_ffmpeg_verbose(&args)
    } else {
        run_ffmpeg(&args)
    }
}
```

This scales the smaller dimension to match 1080x1920 while preserving aspect ratio, then center-crops to exact 1080x1920. For iPhone portrait (already ~9:16), cropping is 0 or minimal.

**2. Integrate into `pipeline.rs` `run_stages()`:**

Before the existing Stage 1 (normalize), add a new Stage 0 that probes source dimensions and scales if needed:

```rust
// Stage 0: Scale to TikTok resolution (skip if already 1080x1920)
let input_str_for_scale = input.to_string_lossy().to_string();
let dims = ffmpeg::probe_dimensions(&input_str_for_scale);
let scaled_input = if dims != Some((tiktok::OUTPUT_WIDTH, tiktok::OUTPUT_HEIGHT)) {
    eprintln!("\n{}", "Stage 0: scale to 1080x1920".bold());
    let scaled_path = temp_dir.join("scaled.mp4");
    let scaled_str = scaled_path.to_string_lossy().to_string();
    let result = ffmpeg::scale_to_tiktok(&input_str_for_scale, &scaled_str, verbose);
    match result {
        Ok(ref o) if o.success => {
            if let Some((w, h)) = dims {
                eprintln!("\u{2713} Scaled {}x{} -> 1080x1920", w, h);
            } else {
                eprintln!("\u{2713} Scaled to 1080x1920");
            }
            scaled_path
        }
        Ok(o) => {
            let truncated = crate::error::last_n_lines(&o.stderr, 20);
            return Err(AppError::FfmpegFailed {
                stage: "scale".to_string(),
                code: o.exit_code.unwrap_or(-1),
                stderr: truncated,
            }.into());
        }
        Err(io_err) => {
            return Err(AppError::StageIo {
                stage: "scale".to_string(),
                source: io_err,
            }.into());
        }
    }
} else {
    input.to_path_buf()
};
```
