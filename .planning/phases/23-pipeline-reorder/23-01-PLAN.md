Purpose: When Whisper runs on the already-cut video, its timestamps match the final timeline exactly. This eliminates the need for post-hoc timestamp adjustment and the caption drift artifacts that adjustment introduced.

Output: Modified `src/commands/pipeline.rs` with new stage order and no timestamp adjustment logic in the pipeline path.

**C. Handle the empty-speeches early-return:**
In the current code, the empty-speeches path (lines 336-356) references `words` which was populated by transcribe. In the new order, transcribe hasn't run yet. For the empty-speeches case: copy normalized to cut.mp4, then fall through to transcription (don't return early). The pipeline should still transcribe and caption even if no silence was detected. Restructure so that when `speeches.is_empty()`:
```rust
if speeches.is_empty() {
    eprintln!("No speech detected -- skipping cut stage");
    let cut_output = temp_dir.join("cut.mp4");
    std::fs::copy(&normalized, &cut_output).map_err(|e| AppError::StageIo {
        stage: "copy-normalized".to_string(),
        source: e,
    })?;
    // Don't clean up normalized yet -- but we can since we copied
    let _ = std::fs::remove_file(&normalized);
    registry.remove(&normalized);
    // Fall through to transcription with cut_output
}
```
Then let `cut_output` be available for the transcription stage below regardless of whether cutting happened. Use a `let cut_output = ...` binding that's visible to both paths.

Move the transcribe call (currently lines 301-308) after the cut block. Update banner from `"Stage 3/7: transcribe"` to `"Stage 4/7: transcribe"`. Change the transcribe call per D-04:
