Define OverlayArgs:
```rust
#[derive(Args)]
pub struct OverlayArgs {
    /// Input video file
    pub input: PathBuf,

    /// Text to overlay on video
    #[arg(long)]
    pub text: String,

    /// Output path (default: input_overlay.mp4)
    #[arg(short = 'o')]
    pub output: Option<PathBuf>,

    /// Path to .ttf font file
    #[arg(long)]
    pub font: Option<PathBuf>,

    /// Font size in pixels
    #[arg(long, default_value = "48")]
    pub font_size: u32,

    /// Font color (FFmpeg color name or hex)
    #[arg(long, default_value = "white")]
    pub color: String,

    /// Position preset: top, center, bottom
    #[arg(long, default_value = "center")]
    pub position: String,

    /// When overlay appears (seconds)
    #[arg(long, default_value = "0.0")]
    pub start: f64,

    /// How long overlay is visible (seconds, 0 = entire video)
    #[arg(long, default_value = "0.0")]
    pub duration: f64,
}
```

Create `src/commands/overlay.rs` with `pub fn run(args: OverlayArgs, verbose: bool, registry: &TempFileRegistry) -> anyhow::Result<()>`:

1. Call `require_ffmpeg()?`
2. Validate input exists
3. Derive output path with suffix "overlay"
4. Build drawtext filter string:
   - Base: `drawtext=text='<escaped>':fontsize=<size>:fontcolor=<color>`
   - Position: `x=(w-text_w)/2` always. For y: `top` → `y=260`, `center` → `y=(h-text_h)/2`, `bottom` → `y=h-330`
   - If font provided: add `fontfile='<path>'`
   - If duration > 0: add `enable='between(t,<start>,<start+duration>)'`
   - If duration == 0 and start > 0: add `enable='gte(t,<start>)'`
5. Build FFmpeg args: `["-i", input, "-vf", drawtext_filter, "-c:a", "copy", temp_output]`
6. Run FFmpeg with spinner/verbose pattern (same as cut.rs)
7. Copy temp to output, clean up, show success message

Escape text for FFmpeg drawtext: replace `'` with `'\''`, `:` with `\:`, `\` with `\\`.

Add a helper to `src/ffmpeg.rs`:
```rust
pub fn run_ffmpeg_capture_stdout(args: &[&str]) -> Result<(FfmpegOutput, Vec<u8>), std::io::Error>
```
This variant captures stdout (piped instead of null) so we can read loudnorm measurement JSON from first pass. FFmpeg loudnorm prints measurement data to stderr, so we can use `run_ffmpeg()` which already captures stderr.

Create `src/commands/normalize.rs` with `pub fn run(args: NormalizeArgs, verbose: bool, registry: &TempFileRegistry) -> anyhow::Result<()>`:

1. Call `require_ffmpeg()?`
2. Validate input exists
3. Derive output path with suffix "normalized"

**Pass 1 — Measure loudness:**
4. Build args: `["-i", input, "-af", "loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json", "-f", "null", "/dev/null"]`
5. Run FFmpeg (non-verbose always for pass 1), capture stderr
6. Parse the loudnorm JSON block from stderr:
   - Find the line starting with `{` after `[Parsed_loudnorm` in stderr
   - Extract `input_i`, `input_tp`, `input_lra`, `input_thresh`, `target_offset` values
   - Use simple string parsing (find key, extract value between quotes)

**Pass 2 — Apply normalization:**
7. Build loudnorm filter with measured values:
   ```
   loudnorm=I=-14:TP=-1.5:LRA=11:measured_I=<input_i>:measured_TP=<input_tp>:measured_LRA=<input_lra>:measured_thresh=<input_thresh>:offset=<target_offset>:linear=true
   ```
8. Build args: `["-i", input, "-af", loudnorm_filter, "-c:v", "copy", temp_output]`
9. Run FFmpeg with spinner/verbose pattern
10. Copy temp to output, clean up, show success message

Show two-phase progress: spinner says "Analyzing loudness..." for pass 1, "Normalizing audio..." for pass 2.
