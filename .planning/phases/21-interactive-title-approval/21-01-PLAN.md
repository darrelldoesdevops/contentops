  <name>Task 1: Add --no-interactive flag and refactor generate_title to return multiple options</name>
  <files>src/cli.rs, src/commands/overlay.rs</files>
  <action>
  **cli.rs changes:**
  - Add `#[arg(long)] pub no_interactive: bool` to PipelineArgs
  - Add `#[arg(long)] pub no_interactive: bool` to OverlayArgs

  **overlay.rs changes:**
  1. Rename `generate_title()` to `generate_title_options()`, make it `pub`, change return type to `anyhow::Result<Vec<String>>`
  2. Update the Claude prompt to request 3 options separated by `---` delimiter:
     - Keep existing constraints (3-8 words, 2-3 lines each, hook-style)
     - Add: "Generate exactly 3 different title options. Separate each option with --- on its own line."
  3. Parse response by splitting on `---`, trimming, filtering empty strings
  4. If parsing yields fewer than 2 options, wrap entire response as single-element Vec
  5. Spinner pattern: keep existing make_spinner -> finish_and_clear on error, finish_with_message("Title options generated") on success

  6. Add new `pub fn approve_title()` function:
     ```
     pub fn approve_title(options: &[String], no_interactive: bool, verbose: bool) -> anyhow::Result<String>
     ```
     - If `no_interactive || !std::io::stdin().is_terminal()`:
       - Print: "Auto-selected title: \"{first_option}\""
       - Return first option
     - Otherwise:
       - Build items list: each option (truncated to first line for display) + "Custom..." as last choice
       - Use `dialoguer::Select::new().with_prompt("Select a title").items(&items).default(0).interact()?`
       - If user picks an option: return that full option string (not truncated)
       - If user picks "Custom...": use `dialoguer::Input::new().with_prompt("Enter custom title").interact_text()?`
       - Print chosen title with checkmark prefix: `eprintln!("✓ Title: \"{}\"", chosen)`
       - Return chosen title

  7. Update `run()` in overlay.rs:
     - When `args.auto` is Some: call `generate_title_options()` then `approve_title()` instead of old `generate_title()`
     - Pass `args.no_interactive` through to `approve_title()`

  8. Add unit tests:
     - `parse_title_options_three_options`: verify splitting "A\n---\nB\n---\nC" yields 3 items
     - `parse_title_options_no_delimiter`: verify single response wraps to Vec with 1 item
     - `parse_title_options_empty_sections`: verify empty sections between delimiters are filtered
  </action>

  </verify>

  - `approve_title()` handles interactive selection, custom input, and non-interactive fallback
  - `overlay::run()` uses new approval flow when `--auto` is set
  - Parse tests confirm delimiter splitting and fallback behavior
