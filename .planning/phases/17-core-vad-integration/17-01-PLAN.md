  <action>
1. Add `hound = "3.5"` to `[dependencies]` in Cargo.toml.

2. Create `src/vad.rs` with a `run_vad` function:
   - Signature: `pub fn run_vad(wav_path: &Path, video_duration: f64) -> anyhow::Result<Vec<SpeechInterval>>`
   - Read WAV with `hound::WavReader::open(wav_path)`, verify 16kHz mono via `spec()`
   - Build VAD: `VoiceActivityDetector::builder().sample_rate(16000i64).chunk_size(512usize).build()` -- map error to `anyhow::anyhow!("ONNX Runtime failed to initialize: {}", e)`
   - Collect all samples as `Vec<i16>` via `reader.samples::<i16>().filter_map(|s| s.ok()).collect()`
   - Use `LabelIterator`: `samples.into_iter().label(&mut vad, 0.5f32, 0usize)` -- threshold 0.5, padding_chunks 0 for aggressive cutting
   - Track `chunk_idx` to reconstruct timestamps: start = `chunk_idx as f64 * 512.0 / 16000.0`, end = `(chunk_idx + 1) as f64 * 512.0 / 16000.0`
   - Accumulate contiguous Speech chunks into `SpeechInterval { start, end }` (from `crate::silence::SpeechInterval`)
   - Flush trailing speech at end of iterator
   - Clamp final interval's end to `video_duration` (prevents overshoot from zero-padded final chunk)
   - Add a `const VAD_THRESHOLD: f32 = 0.5;` at module top for easy tuning
   - Import: `use voice_activity_detector::{IteratorExt, LabeledAudio, VoiceActivityDetector};`
   - Import: `use crate::silence::SpeechInterval;`

3. Add `extract_16k_wav` to `src/ffmpeg.rs`:
   - Signature: `pub fn extract_16k_wav(input: &str, dest: &Path, verbose: bool) -> Result<(), std::io::Error>`
   - Build args: `["-i", input, "-ar", "16000", "-ac", "1", "-f", "wav", &dest_str]`
   - Call `run_ffmpeg_verbose(&args)` if verbose, else `run_ffmpeg(&args)`
   - Check `output.success`; if false, return `Err(std::io::Error::new(ErrorKind::Other, ...))`
   - Needs `use std::path::Path;` (already imported in ffmpeg.rs)

4. Register the new module in `src/main.rs`: add `mod vad;` alongside existing module declarations.

5. Run `cargo build` to verify compilation. Run `cargo clippy -- -D warnings` to verify no warnings.
