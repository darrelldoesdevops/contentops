1. Modify `transcribe()` signature to accept an optional pre-extracted WAV path:
   ```rust

       input: &Path,
       model: &Path,
       lang: &str,
       verbose: bool,
       registry: &TempFileRegistry,
       wav_path: Option<&Path>,  // NEW: if Some, use this WAV instead of extracting
   ) -> anyhow::Result<Vec<Word>>
   ```

2. Inside `transcribe()`, branch on `wav_path`:
   - If `wav_path` is `Some(path)`:
     - Use `path` directly as the WAV file for Whisper -- skip the FFmpeg audio extraction step entirely
     - Set `temp_wav = path.to_path_buf()` for use in the Whisper command
     - Do NOT register it with the registry (caller owns it)
     - Do NOT delete it at end of function (caller manages lifetime)
   - If `wav_path` is `None`:
     - Keep existing behavior: create temp WAV, extract audio via `ffmpeg::extract_16k_wav`, register with registry
     - Replace the inline FFmpeg args with `ffmpeg::extract_16k_wav(&input_str, &temp_wav, verbose)?` (uses the shared helper from Plan 01) -- map error to `AppError::StageIo { stage: "audio-extraction" }`
     - Delete WAV at end of function as before

3. Track whether we own the WAV file with a boolean `owns_wav`:
   - `let owns_wav = wav_path.is_none();`
   - At end of function, only delete temp_wav and whisper JSON if `owns_wav` is true

4. Update the standalone `caption::run()` function:
   - The call to `transcribe()` inside `run()` passes `None` for `wav_path` (no behavior change)
   - Replace the inline audio extraction block (lines ~588-646 in caption.rs run()) with a call to `ffmpeg::extract_16k_wav` via the shared helper -- this deduplicates the third copy of 16kHz extraction
   - Actually, `caption::run()` does its own audio extraction separate from `transcribe()`. Since `run()` calls `transcribe()` which also extracts audio, the `run()` extraction is for a different purpose (it creates SRT/JSON then optionally burns). The `transcribe()` path already handles extraction. Just update the `transcribe()` call in `run()` to pass `wav_path: None`.

5. Run `cargo build` to verify compilation. Ensure `caption` command behavior is unchanged when `wav_path` is `None`.
