  **Helper: print_mismatch_context()**

  Add a helper function that displays the mismatch diff context. This is shown regardless of --verbose:
  ```rust
  fn print_mismatch_context(original: &[Word], corrected: &[Word]) {
      eprintln!(
          "Warning: LLM returned {} words, expected {}",
          corrected.len(),
          original.len()
      );
      // Show first 5 word differences where both arrays overlap
      let min_len = original.len().min(corrected.len());
      let diffs: Vec<_> = original[..min_len].iter()
          .zip(corrected[..min_len].iter())
          .filter(|(o, c)| o.word != c.word)
          .take(5)
          .collect();
      for (orig, fixed) in &diffs {
          eprintln!("  \"{}\" -> \"{}\"", orig.word, fixed.word);
      }
      let diff_count = original.len().abs_diff(corrected.len());
      if corrected.len() > original.len() {
          eprintln!("  ({} word(s) added)", diff_count);
      } else {
          eprintln!("  ({} word(s) removed)", diff_count);
      }
  }
  ```

  **Helper: invoke_claude_fix()**

  Extract the Claude CLI invocation into a reusable helper so both the initial call and retry can use it:
  ```rust
  fn invoke_claude_fix(words: &[Word], verbose: bool, enforce_count: bool) -> anyhow::Result<Option<Vec<Word>>>
  ```
  - Builds the prompt (same as current). If `enforce_count` is true, append: "You MUST return EXACTLY {N} entries. Do NOT add or remove words."
  - Runs `claude -p <prompt> --model haiku`
  - Parses response. On parse failure, returns `Ok(None)`.
  - Returns `Ok(Some(corrected_words))` on success.
  - Manages its own spinner internally (create before CLI call, finish_and_clear on completion or error).

  **Main fix_transcription() refactor:**

  Replace the current mismatch block (lines 358-367) with:

  1. Call `invoke_claude_fix(words, verbose, false)` for the initial attempt.
  2. If result is None (parse failure), print warning and return Ok(()) (same as current behavior).
  3. If corrected.len() == words.len(), apply fixes as current code does (lines 370-385) and return.
  4. If corrected.len() != words.len() (MISMATCH):
     a. Call `print_mismatch_context(words, &corrected)`.
     b. Check TTY: `use std::io::IsTerminal; if !std::io::stdin().is_terminal()`
        - Non-TTY: return `Err(AppError::TranscriptMismatch { expected: words.len(), actual: corrected.len() }.into())`
     c. TTY: Show interactive prompt using dialoguer::Select:
        ```rust
        let choices = &["Use originals (keep timing safe)", "Use fixed (accept word count change)", "Retry (re-run with word count constraint)"];
        let selection = dialoguer::Select::new()
            .with_prompt("How to handle mismatch?")
            .items(choices)
            .default(0)
            .interact()?;
        ```
     d. Match on selection:
        - 0 (Use originals): return Ok(()) — words unchanged, timing safe
        - 1 (Use fixed): apply ALL corrected words to the words slice by iterating up to `min(words.len(), corrected.len())`, updating only the word field (preserve original start/end times). Print how many applied. Return Ok(()).
        - 2 (Retry): call `invoke_claude_fix(words, verbose, true)` with enforce_count=true.
          - If retry returns None (parse failure): fall through to post-retry menu with only first fix available.
          - If retry_result.len() == words.len(): apply fixes and return Ok(()).
          - If retry also mismatches: print all three versions side by side:
            ```
            eprintln!("\nRetry also returned wrong count ({} words).", retry_result.len());
            eprintln!("\nComparison (first 20 words):");
            eprintln!("  Original:  {}", words.iter().take(20).map(|w| w.word.as_str()).collect::<Vec<_>>().join(" "));
            eprintln!("  First fix: {}", corrected.iter().take(20).map(|w| w.word.as_str()).collect::<Vec<_>>().join(" "));
            eprintln!("  Retry fix: {}", retry_result.iter().take(20).map(|w| w.word.as_str()).collect::<Vec<_>>().join(" "));
            ```
            Then show a 4-option dialoguer::Select:
            ```rust
            let post_retry = &[
                "Use originals (keep timing safe)",
                "Use first fix",
                "Use retry fix",
                "Abort pipeline",
            ];
            ```
            - 0: return Ok(())
            - 1: apply first fix words (same min-length apply logic)
            - 2: apply retry fix words (same min-length apply logic)
            - 3: return Err(AppError::TranscriptMismatch { expected: words.len(), actual: retry_result.len() }.into())

  **Important implementation notes:**
  - Always `finish_and_clear()` the spinner BEFORE any dialoguer prompt or eprintln output
  - The "apply fix" logic for mismatched lengths: iterate `0..min(words.len(), fixed.len())`, only update `words[i].word = fixed[i].word.clone()`. Never touch start/end times. Log count of changes.
  - Keep the existing behavior for corrected.len() == words.len() (the happy path, lines 370-385) exactly as-is.
  - The `use std::io::IsTerminal;` import goes at the top of the function or at the file level.
